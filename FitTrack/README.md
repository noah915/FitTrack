# FitTrack

FitTrack is a web-based fitness and nutrition tracker that helps users plan, log, and analyze workouts and meals.

## Features
- Workout tracker (sets, reps, weight)
- Meal planner with calorie tracking
- Progress dashboard with charts
- Goal reminders and achievements

## Tech Stack
React | Node.js | Express | MongoDB | Docker | GCP (Cloud Run) | GitHub Actions

## AI Use
ChatGPT and GitHub Copilot were used to:
- Generate components and backend routes
- Create tests and Docker/CI configs
- Write documentation
